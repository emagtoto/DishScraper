# DishScraper - Recipe Finder App

A modern recipe finder application that searches Spoonacular API and generates AI recipes using DeepSeek.

## Features

- Search recipes by ingredients
- AI-generated recipes with DeepSeek
- Firebase Authentication & Firestore
- Save favorite recipes
- Search history tracking
- Dietary filters & preferences
- Fully responsive design
